# Supabase schema (منبع حقیقت روی Git)

همهٔ تغییرات ساختار دیتابیس فقط از طریق فایل‌های این پوشه انجام می‌شود و در GitHub نگه داشته می‌شود.
اگر پروژهٔ رایگان Supabase بعد از停用/انقضا از دسترس خارج شد، با اجرای همین migrationها روی یک پروژهٔ جدید، ساختار دوباره ساخته می‌شود.

## قانون طلایی

1. در داشبورد Supabase مستقیماً جدول/ستون نساز (مگر موقتی برای تست).
2. هر تغییر schema → یک فایل جدید در `migrations/` با شماره بعدی:
   - `0003_something.sql`
   - `0004_something.sql`
3. فایل را commit و push کن.
4. همان SQL را روی پروژهٔ فعال اجرا کن (SQL Editor یا CLI).

## فایل‌های فعلی

| فایل | کار |
|------|-----|
| `0001_init.sql` | کل اسکیم اولیه: جداول، RLS، trigger، دسته‌ها |
| `0002_iphone_noreg_category.sql` | دستهٔ آیفون بدون رجیستری (برای پروژه‌های قدیمی‌تر) |

> در `0001` همین دسته هم seed شده؛ `0002` برای سازگاری است و اجرای دوباره بی‌خطر است (`ON CONFLICT DO NOTHING`).

## ساخت مجدد روی Supabase جدید (بعد از قطع پروژه قبلی)

1. پروژهٔ جدید در Supabase بساز.
2. کلیدهای جدید را در `.env.local` / Vercel بگذار:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
3. در **SQL Editor** به ترتیب اجرا کن:
   - اول کل محتوای `migrations/0001_init.sql`
   - بعد `migrations/0002_iphone_noreg_category.sql`
4. یا با اسکریپت:

```bash
./scripts/apply-supabase-sql.sh
```

(متن SQL را چاپ می‌کند تا در SQL Editor پیست کنی؛ یا اگر `DATABASE_URL` داشته باشی با `psql` اجرا می‌کند.)

5. `NEXT_PUBLIC_DEMO_MODE=false`
6. محصولات را دوباره از `/admin/products/import` همگام کن (دادهٔ کالا داخل Git نیست؛ فقط ساختار است).

## داده در مقابل ساختار

| چه چیزی | روی GitHub؟ | بعد از تعویض پروژه |
|---------|-------------|---------------------|
| جداول، RLS، enum، دسته | بله (migration) | با اجرای SQL برمی‌گردد |
| محصولات، سفارش‌ها، کاربرها | خیر (داده) | دوباره import / ورود کاربران |

## یادآوری درباره پلن رایگان

پروژهٔ رایگان Supabase بعد از مدتی بی‌استفاده **pause** می‌شود. با migrationهای این ریپو می‌توانی در چند دقیقه پروژهٔ جدید بسازی؛ فقط کلیدهای env را عوض کن و لیست کانال را دوباره همگام کن.
